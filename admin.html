Configuración — Cómo funciona el bono

La comisión se paga completa desde el primer punto. Encima de eso, al llegar a cada nivel de puntos se suma un garantizado adicional.

Nivel 3 (techo)
Regla: la comisión variable se paga completa desde el primer punto — no hay "zona intermedia" con tarifa reducida. Encima de esa comisión, al llegar a los puntos de cada nivel se suma el garantizado de ese nivel. El Nivel 3 es un techo: por encima de esos puntos el garantizado no sigue subiendo (la comisión variable sí sigue creciendo con cada punto).
